\begin{abstract}
% ============================================================
Modern LLM agent platforms allow users to install
third-party \emph{skills}---plugins granting the agent ambient authority
over files, credentials, the shell, and the network.
When multiple skills are co-installed, they share a single agent context,
creating an implicit composition whose aggregate capability set
is never disclosed to the user.
We identify and formalize a new attack class---
\emph{skill composition attacks}---in which an adversary exploits
this gap by poisoning a benign \emph{source} skill's output channel
to trigger an undisclosed dangerous capability of a co-installed
\emph{sink} skill, without any user action beyond normal agent use.

We make four contributions.
First, we design \lscps (Layered Structured Capability Pattern Search),
a static analysis framework that identifies dangerous source-sink pairs
across a marketplace corpus using \NpatternsLSCPS{}+ regex patterns
organized into five sink capability families (shell, filesystem,
network exfil, memory, persistence) and five source injection channels.
Applied to \NskillsCH{} \clawhub{} skills, \lscps identifies \NsinkCH{}
sink skills with undisclosed dangerous capabilities and \NsrcCH{}
viable source skills.
Second, we validate this surface with a two-stage LLM audit
using chain-of-thought reasoning on SKILL.md documentation,
confirming \NcodexConfirm{} viable attack paths in \skillssh{}.
Third, we demonstrate the attacks on two live agent platforms.
On \clawhub{} (OpenClaw agent, \NpairsCH{} source-sink pairs):
all \NpairsCHshell{} shell-execution sink pairs succeed (\PairsCHshellRate{})
and \NpairsCHConeok/\NpairsCHCone{} LLM-context injection pairs succeed (\PairsCHConeRate{}).
On \skillssh{} (Codex agent, \NpairsSS{} Codex-confirmed pairs):
\NpairsSSsuccess/\NpairsSSlaunched{} pairs produce verified dangerous
side effects (\PairsSSrate{}), spanning all five sink channel types,
with zero install-time safety gates triggered.
These results establish skill composition attacks as a concrete,
cross-platform threat requiring mandatory capability isolation
at the agent ecosystem level.
\end{abstract}
